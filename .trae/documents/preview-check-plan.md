# Vue Blog 项目预览检查计划

## 目标
启动项目预览服务器，检查各个页面是否正常工作，有无报错或样式问题。

## 检查步骤

### 步骤 1: 启动预览服务器
- 使用 `npm run preview` 或 `npm run dev` 启动项目
- 等待服务器启动完成
- 获取预览 URL

### 步骤 2: 检查首页 (Home.vue)
- 访问首页 `/`
- 检查文章列表是否正常显示
- 检查文章标题、日期、标签、摘要是否显示正确
- 检查分页功能是否正常
- 检查控制台是否有报错

### 步骤 3: 检查文章详情页 (Post.vue)
- 点击任意文章进入详情页
- 检查文章标题、日期、标签是否显示
- 检查 Markdown 内容是否正确渲染
- 检查图片是否正常加载
- 检查上一篇/下一篇导航是否显示
- 检查控制台是否有报错

### 步骤 4: 检查标签页 (Tag.vue)
- 访问 `/tags` 或点击标签
- 检查标签列表是否显示
- 检查标签文章数量是否正确
- 检查点击标签后过滤的文章列表是否正确
- 检查控制台是否有报错

### 步骤 5: 检查归档页 (Archive.vue)
- 访问 `/archive`
- 检查归档数据是否按年份和月份分组
- 检查文章列表是否显示
- 检查控制台是否有报错

### 步骤 6: 检查关于页 (About.vue)
- 访问 `/about`
- 检查关于内容是否正常显示
- 检查控制台是否有报错

### 步骤 7: 检查响应式布局
- 切换到移动设备视图（H5 模式）
- 检查各页面在移动端的显示效果
- 检查是否有布局错乱或样式问题

### 步骤 8: 检查暗黑模式
- 切换暗黑模式
- 检查各页面在暗黑模式下的样式
- 检查 header、footer、container 背景色是否一致
- 检查文字颜色是否可读

### 步骤 9: 检查路由和导航
- 检查所有路由是否能正常跳转
- 检查是否有 "No match found" 警告
- 检查特殊字符标签（如 CI/CD）的编码是否正确

## 预期结果
- 所有页面无 JavaScript 错误
- 控制台无严重警告
- 样式正常，无布局错乱
- 暗黑模式切换正常
- 响应式布局正常
- 路由跳转正常
